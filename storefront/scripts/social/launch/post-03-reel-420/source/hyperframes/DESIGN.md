# Enrola Shop — Visual Identity

Brand: Venezuelan smoking accessories e-commerce. Tone: warm, irreverent, neobrutalist street energy. Spanish from Venezuela (tuteo, NEVER voseo).

## Style Prompt

Neobrutalist editorial poster aesthetic — chunky borders, hard offset shadows, no rounded corners, no gradients. Cream paper background with multiply noise grain. Headlines in Kanit Black, oversized (90-200px), uppercase, tight tracking. Color blocking around accent elements (orange code pills, dark badges). Off-axis rotations (-1.5° to -3°) on hero callouts to add hand-stamped energy.

## Colors

- `--cream: #F5F2E8` — primary background (light scenes)
- `--background-dark: #221610` — dark scene background
- `--dark: #1A1A1A` — primary foreground / borders / shadows
- `--primary: #BB3B2E` — burnt brick red (links, accents on light bg)
- `--orange: #FF3B27` — vivid orange (code pills, accents on dark bg)
- `--secondary: #4D5431` — olive (eyebrows, secondary labels)

## Typography

- **Family:** Kanit (Google Fonts) — weights 400, 500, 600, 700, 900
- **Headlines:** Kanit Black 900, uppercase, tracking -0.03 to -0.04em, line-height 0.9-0.92
- **Body / steps:** Kanit Bold 700, slight letter-spacing
- **Labels / eyebrows:** Kanit SemiBold 600-700, tracking 0.18em, uppercase

## Motion

- **Energy:** HIGH (promo/launch). Snappy entrances 0.4-0.6s. Easing: `back.out`, `power3.out`, `expo.out`.
- **Transitions between scenes:** crossfade + scale (0.25-0.3s, `power3.inOut`). Same primary across all transitions for consistency.
- **Ken Burns** on hero scenes: slow scale 1.0 → 1.05 over scene duration with `sine.out`.
- **Pulses** on hero codes/clocks: scale 1.0 → 1.06 → 1.0 over 0.4s with `power2.inOut`.

## What NOT to Do

- ❌ No voseo (entrá / armá / aplicá) — Venezuelan tuteo only (entra / arma / aplica)
- ❌ No rounded corners — neobrutalist hard edges only
- ❌ No gradients on text or backgrounds — solid colors with hard offset shadows
- ❌ No emoji except `⏰` for urgency callouts (sparingly)
- ❌ No "drug paraphernalia" trigger words (avoid IG moderation flags)
